# CloudDesk data policy, version 1

## DATA-01: Export and deletion
Owners and admins can export workspace records as CSV from Settings > Data > Export. Exported CSV files do not include file attachments. Attachments must be downloaded separately before deletion. Only the owner can request workspace deletion. Deletion has a 7-day grace period during which the owner can cancel the request. After the grace period ends, active workspace data is permanently deleted and cannot be recovered through support. Billing cancellation and workspace deletion are separate operations.

## DATA-02: Residency and unavailable details
A workspace's primary storage region is chosen as EU or US at creation and cannot be changed through self-service. A migration request requires support review; approval is not guaranteed. This policy does not specify backup retention duration, backup locations, HIPAA eligibility, or a maximum export file size. These details require confirmation from support. The assistant has no access to a customer's live workspace or export status.
