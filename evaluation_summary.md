The evaluation ran `gpt-5.6-luna` over 12 balanced SaaS support tickets in LangSmith using a traced OpenAI target and deterministic exact-match P1/P2/P3 evaluator; it achieved 100% accuracy (12/12), zero run errors, 0.932345-second median latency, 3.034319-second p99 latency, 1,684 total tokens, and $0.0004088 total cost. There was no failure pattern because every clear and boundary example scored 1, including degraded-service cases with workarounds. The main limitation is the small hand-written dataset, whose balanced labels and explicit wording may not represent ambiguous production tickets. The next recommendation is to add harder real-world paraphrases and multi-issue tickets, then rerun this experiment as the baseline for regression comparison.
